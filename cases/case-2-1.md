# 案例2.1（德国）：电子制造——西门子安贝格工厂用AI预测哪些电路板需要X光检测、提前12至36小时预警设备故障

**行业／场景**：（大型企业：西门子安贝格电子工厂，2017年西门子资料称员工约1200人）工厂生产Simatic工控产品，产品组合约1200种，每年约1700万件。场景是PCB产线的X光检测和关键设备的预测性维护。

**痛点**：PCB产线末端的自动X光检测工位是瓶颈，再加购一台X光机约需50万欧元。另外，用于电路板分板的铣削主轴常因铣屑粉尘工作异常，造成非计划停机。

**AI方案**：把产线传感器和工艺参数数据传到云端训练模型，模型部署在工厂边缘设备上，根据工艺参数预测电路板焊点是否合格、是否需要做终检。针对铣削主轴，团队找出主轴转速和驱动电流这两个与非计划停机相关的参数，用边缘设备上的预训练算法识别异常，结果在Insights Hub（原名MindSphere）中展示。

**落地效果**：据西门子2019年的演讲材料，必要的X光检测最多减少30%，省下了加购一台X光机的50万欧元投资；铣削主轴故障可以提前12至36小时预警。（口径：企业自述，西门子官网与西门子在ETSI AI峰会的演讲材料）

**适用企业画像**：检测工位成为产能瓶颈、关键设备停机代价高、已在采集工艺参数的电子和精密制造企业。
