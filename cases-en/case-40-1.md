# Case 40.1 (Australia): Software & IT Services — ANZ Bank runs a randomized controlled experiment before rolling out GitHub Copilot; the experimental group's task completion time is about 42% shorter on average

**Industry / scenario**: (Large enterprise: ANZ has more than 5,000 engineers) The bank's internal software engineering teams. The scenario is a controlled experiment run before a full rollout of an AI coding assistant.

**Pain point**: As AI coding tools became widespread, ANZ wanted first to evaluate, in a controlled environment, how GitHub Copilot performs on real engineering tasks, covering productivity, code quality and security.

**AI solution**: A 6-week experiment ran from mid-June to the end of July 2023 (2 weeks of preparation, 4 weeks of formal testing). More than 100 engineers were randomly split into two groups: the Copilot group had the GitHub Copilot plugin enabled, and the control group had it disabled. Both groups solved the same algorithm problems in Python.

**Results**: The paper says Copilot raised ANZ engineers' productivity by an average of 42.36%, a figure calculated from task completion time (a calculation formula elsewhere in the paper gives 42.34%). Methods written by the Copilot group had a 12.86% higher success rate, but the paper itself says this result is not statistically significant. The experiment did not yield valid data for measuring code security. Early data afterward from about 1,000 engineers also showed clear gains in productivity and job satisfaction. (Basis: research paper written by ANZ employees, an arXiv preprint whose comments note it is included in the SEC 2024 conference proceedings; The Register published a media write-up)

**Who this fits**: Companies with large engineering teams and strict compliance requirements (such as banks) that want to use data to decide whether to roll out AI coding tools across the board.

*Sources: arXiv, "The Impact of AI Tool on Engineering at ANZ Bank An Emperical Study on GitHub Copilot within Coporate Environment" (2024-02-08, Sayan Chatterjee et al.)
